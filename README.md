# Floating Draggable Menu

Radial menu you can drag around the viewport.

![Screenshot](github-contents/screenshot.png)

**Live demo:** [https://rogue-dev-studio.github.io/floating-draggable-menu/](https://rogue-dev-studio.github.io/floating-draggable-menu/)

## Highlights
- Drag to reposition
- Radial open/close

## Run
Open `index.html` locally (Live Server on port **5500**), or use the live demo above.

```bash
git clone https://github.com/rogue-dev-studio/floating-draggable-menu.git
```
